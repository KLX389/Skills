# Style Rules

The skill is Zinsser-inspired, not an imitation of copyrighted prose. Apply the practical principles without quoting or paraphrasing long passages from the book.

## Diagnosis Categories

Use these categories to find the highest-impact edits:

- Clutter: filler, repetition, throat-clearing, inflated transitions, meta-commentary.
- Verbs: passive voice, nominalizations, weak helper verbs, delayed action.
- Concreteness: abstract nouns, vague claims, missing examples, blurred actors.
- Structure: slow opening, buried point, weak final sentence, paragraph order.
- Rhythm: sentences with identical length, overloaded clauses, breathless lists.
- Voice: institutional, bureaucratic, hedged, impersonal, or needlessly formal tone.

## Clutter Cuts

Delete or replace phrases that add weight without adding meaning.

| Pattern | Better move |
| --- | --- |
| `grundsätzlich`, `eigentlich`, `gewissermaßen`, `in gewisser Weise` | Delete unless the qualification is factual. |
| `sehr`, `wirklich`, `äußerst`, `unglaublich` | Delete or choose a stronger concrete word. |
| `im Rahmen von`, `im Hinblick auf`, `in Bezug auf` | Use `bei`, `für`, `zu`, `über`, or a direct verb. |
| `zum jetzigen Zeitpunkt` | Use `jetzt`. |
| `eine Entscheidung treffen` | Use `entscheiden`. |
| `eine Verbesserung erzielen` | Use `verbessern`. |
| `zur Verfügung stellen` | Use `geben`, `liefern`, `bereitstellen`, or the exact action. |
| `es besteht die Möglichkeit` | Use `kann`, if the possibility is real. |
| `it is important to note that` | State the point directly. |
| `in order to` | Use `to`. |
| `due to the fact that` | Use `because`. |

## Active, Concrete Prose

Prefer a sentence where a visible actor does a clear action.

Weak:

```text
Eine Optimierung der Prozesse wurde vorgenommen.
```

Stronger:

```text
Das Team hat den Ablauf vereinfacht.
```

Do not force active voice when the actor is unknown, irrelevant, or intentionally hidden. In those cases, make the sentence clear without inventing an actor.

## Openings And Endings

The first sentence should give the reader a reason to continue. Cut delayed openings such as long context setup, apologies, process history, and soft disclaimers unless they carry necessary information.

The last sentence should leave the reader with the central point, consequence, decision, or next step. Avoid endings that trail off into generic summaries.

## Human Voice

Write like a competent person speaking to another competent person. Replace official fog with plain phrasing. Keep warmth when it serves the text, but avoid marketing gloss, false intimacy, and artificial drama.

Preserve real uncertainty. Replace hedging like `it seems that`, `one could argue`, or `possibly in some cases` with a direct statement of what is known, unknown, or conditional.

## Revision Mantra

Draft for yourself. Revise for the reader. Cut what neither side needs.
